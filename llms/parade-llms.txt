# Parade

> Parade is an AI-powered capacity-management and carrier-access platform for freight brokers. It layers on top of a broker's TMS and load boards to find truck availability, syndicate loads, and digitally transact quotes and bookings with carriers and integration partners. Backed by Menlo Ventures.

This file is generated by the API Evangelist enrichment pipeline from the Parade syndication OpenAPI and public docs.

## APIs

- [Parade Transactions API](openapi/parade-digital-transactions-openapi.yaml): Digital transactions — quotes, bookings, available trucks, carrier onboarding status. Base: https://api.capacity.parade.ai
- [Parade Load Feed](openapi/parade-load-sync-openapi.yaml): Search and bulk-sync available loads (paginated). Base: https://api.syndication.parade.ai
- [Parade Syndication Webhooks](openapi/parade-partner-webhooks-openapi.yaml): Partner-side receivers for digital-conversion (quote/booking) and carrier-sync notifications.
